⤓ Baixar .torrent

Automático: direto para o qBittorrent

Como o DublaSync roda no mesmo servidor do qBittorrent, ele pode adicionar o torrent sozinho no fim de cada filme.

  1. Em Configurações → qBittorrent, ligue “Enviar ao qBittorrent”, preencha endereço, usuário e senha e clique Testar conexão.
  2. Confira a tradução de pastas: o mesmo disco aparece com nomes diferentes para cada app (ex.: /media/HD 8TB aqui e /HD 8TB no qBittorrent).
  3. Pronto: cada filme concluído aparece no qui/qBittorrent, confere o arquivo e fica “Semeando”.

Manual (pelo qui)

  1. Baixe o .torrent (botão acima) e, no qui, clique “Adicionar Torrent”.
  2. Em “Caminho de salvamento”, coloque a pasta onde o MKV está, do jeito que o qBittorrent enxerga (ex.: /HD 8TB/Filmes).
  3. Não marque “Pular verificação”: ele confere, chega a 100% e fica “Semeando”. Se começar a baixar do zero, o caminho está errado.
  4. Não renomeie nem edite o MKV depois — isso quebra o torrent.

Para os outros conseguirem baixar de você

  1. Mande o .torrent ou o link magnet.
  2. No qBittorrent: Configurações → Conexão → ative UPnP/NAT-PMP, ou abra a porta de entrada no roteador para o IP do servidor.
  3. Para torrents públicos, deixe DHT, PeX e Descoberta local ligados (Configurações → BitTorrent).
  4. Tracker privado: ligue “Torrent privado”, use só o announce do seu perfil no site, envie pelo Upload do site e adicione no qBittorrent o .torrent que o site devolve.

Compartilhe só conteúdo que você tem direito de distribuir e siga as regras de cada tracker.
